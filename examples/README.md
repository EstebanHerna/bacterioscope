# Example plate images

Raw images to upload into the Streamlit demo, the CLI, or the API — these are
**inputs**, not outputs. Do not confuse them with `data/processed/validation_figures/`,
which holds pipeline *outputs* (annotated images generated by
`scripts/validate_measurement.py`); uploading one of those back into the app as
if it were a fresh photo will produce nonsense results, because it already has
circles, boxes and text drawn on it.

## synthetic/

8 generated Mueller-Hinton plates covering different clinical scenarios (pan-susceptible,
MDR, mixed S/I/R, 12-disk panel, carbapenem-resistant, uneven lighting, large zones,
ESBL-like). Regenerate with `python scripts/generate_test_plates.py`.

- `synthetic/*.png` — upload these.
- `synthetic/reference_annotated/*.png` — the same plates with the expected zone
  circles and categories already drawn on, for visual comparison only. **Do not
  upload these into the app.**

## real/

Real clinical Kirby-Bauer plate photographs used for manual testing (not part of the
UZH/Dryad validation set, which lives in `data/raw/dryad_uzh/` and is not committed
to this repository). Source: internal test set ("astimp"); license/provenance not
fully documented -- do not redistribute outside this repository without checking.

Upload any of these directly; expect lower accuracy than on the synthetic plates
since YOLOv8 is still early in training (see `docs/VALIDATION_REPORT.md`).
