# Synthetic geometry exercises — draft pack

These seven original SVGs are measurement-practice diagrams, not photos of cultures or biological AST results. Each graded SVG contains a known vector circle, a visible 10 mm scale bar, and a 6 mm center disk used only as a drawing cue. Browser resizing preserves the ratio between the zone and scale bar.

`manifest.yaml` is the case inventory and source of truth for IDs, geometry, answer references, tolerance, SHA-256, feedback, and review status. Cases 1–5 ask for a diameter; cases 6–7 teach the learner to flag an ambiguous/truncated illustration as needing review.

**All cases are draft and disabled.** The ±1.0 mm tolerance is a provisional usability choice for these clean vector diagrams, not a validated learning threshold, CLSI Essential Agreement, a clinical acceptance limit, or evidence about the image-analysis pipeline. A qualified microbiology instructor must review the cases and pilot whether this tolerance fits the learners before enabling grading.

These files are separate from `examples/synthetic/`, whose generated plate scenarios and zone values are tied to a software test generator and include invented susceptibility-style labels. No `reference_annotated` image is a quiz input.
